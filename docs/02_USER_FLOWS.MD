
# Floza User Flows

## 1. Purpose

This document defines how different users interact with the Floza website.

The main users are:

1. Website visitors
2. Potential clients
3. Admin/Floza owner

The goal is to create a smooth path from:

Visitor → Interested Lead → Qualified Client

---

# 2. Main Visitor Journey

## Flow Overview

```

Visitor arrives
↓
Views homepage
↓
Understands Floza services
↓
Explores demos/projects
↓
Interacts with AI assistant or inquiry form
↓
Lead information collected
↓
Floza follows up

```

---

```

Visitor opens AI assistant demo
↓

↓

↓

↓

# 16. Important User Experience Rules

The website should:

✓ Explain value quickly  
✓ Avoid overwhelming visitors  
✓ Make contacting Floza easy  
✓ Show proof through demos  
✓ Guide visitors toward becoming leads  


The website should not:

✗ Hide contact options  
✗ Require unnecessary steps  
✗ Use confusing technical language  
✗ Make visitors search for information
```
